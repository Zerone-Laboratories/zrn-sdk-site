Status and gaps

What v2 does not do at the pinned commit, and what this site did not check.

The SDK

  • C only. No Python or Rust bindings, no C++ wrapper.
  • No store package yet. .zexec format 2 is coming. There is no zrn pack, verify, install or submit.
  • No picture tool. v1's zrn render is gone. Draw offscreen with Zroot_render, as this site does.
  • Not included from WP 8.1, as the headers list them: dialog Closing, FullSizeDesired, TitleTemplate; hub background parallax, section header templates, DefaultSectionIndex.
  • Selawik is Latin only. Other scripts need fontconfig and a system font.

This site

  • The pictures and clips come from zrnui's GLES2 renderer through Mesa on a laptop, not from a phone's GPU. Small differences are possible.
  • Pictures are drawn at 3 device pixels a point, clips at 2. The S9 draws at 4.
  • The table of animation numbers is read from source and docs, not measured on a phone.
  • tools/zrn run was not run for this site: no phone was used.

Checked against zrn-sdk commit 71a5ace (SDK v2). Pictures and clips are drawn by zrnui's GLES2 renderer, offscreen, from code that compiled, against the zrn-sdk working tree on top of that commit (it adds the app bar measured on a Windows Phone 8.1 phone and the Segoe WP font lookup), in Segoe WP.
