Status and gaps

libzrnui is a laptop-proven first round. This page lists what is missing, as of commit 8f6fb14, so that nobody has to discover it the hard way.

Not proven

  • Nothing from zrn-sdk has been reported running on a phone by DESIGN.md at this commit. Frame times on the Mali-G72 are inferred, not measured. CPU cost was measured on a 2012 laptop: about 1.35 ms a frame in zrnCoolStyle and 0.78 ms in Metro.
  • No aarch64 build on a laptop. There is no local cross compiler. The store's CI is meant to build aarch64 on an ARM runner.
  • The store has not carried a real app end to end.
  • zrn run as a visible window has not been tried: only --headless in kwin_wayland. Weston has not been tried here either.
  • The signature format has not been checked against the real minisign program.

Missing from libzrnui

  • Pictures, avatars, tabs and pivots, long virtualised lists, dialogs, menus, pickers, date and time, pull to refresh.
  • Any app-level animation call, custom drawing, or custom style.
  • Password or multi-line fields, and your own icons on a row.
  • Bidirectional text, screen reader names and other accessibility.
  • Notifications, stored settings, and the battery and performance calls that the older SDK has.
  • DotMatrix: such a session falls back to Metro.

Missing from the platform

  • Permissions are not enforced.
  • The phone's store app does not list these apps yet, so it cannot install, update or disable them. That includes acting on a revocation.
  • libzrnui and zrn-exec are not in the system image. Until they are, use --bundle-zrnui, though zrn-exec itself still has to be present.
  • Only GitHub is accepted as a source host.

In progress, not on this site yet

Work on pictures, tabs, long lists and input is in the SDK's working tree but is not merged, so it is not documented here. These pages will gain it once it lands.

About this site

  • The element pictures came from zrn render on a laptop's GPU, and busy, toast and the page-change frames from kwin_wayland's virtual backend. None came from a phone.
  • The older Python SDK and ZrnMetroCore were read from source, and were not run for this site.
  • The animation demos are web ports of the formulas. The differences are listed there.

Checked against zrn-sdk commit 8f6fb14. Pictures are real renders of code that compiled. Source and proof.
