Build and ship

Build on your computer for aarch64, then upload and run on the phone with one script, tools/zrn. It is cmake, podman, rsync and ssh, nothing more.

Store packages are coming

The store's .zexec format 2 for v2 apps is not committed yet. v1's zrn pack, zrn submit and zrn verify are gone. Today a v2 app reaches a phone through tools/zrn run, or as a system package. How the store will take it: Publish to the store.

One time on the computer

Needs podman, qemu-user-static with binfmt for aarch64, clang, lld, cmake, ninja, rsync and ssh.

tools/zrn sysroot          # an Arch Linux ARM container, exported to ~/.cache/zrn/sysroot

It takes some minutes, because the container runs under qemu. The cross build links against this sysroot, so the libraries match the phone's.

One time per phone

tools/zrn -p - setup-key 192.168.7.2     # asks for the password, copies your ssh key

The user is alarm unless you give -u. -i picks a key. Nothing is stored: not the password, the user or the host. Use -p - or ZRN_PASSWORD, not a password on the command line.

Every time

tools/zrn run 192.168.7.2 examples/helloworld

This builds with the phone-release preset, uploads the changed bytes, and starts the app over ssh with its output in your terminal. Ctrl-C stops it.

CommandWhat it does
tools/zrn build <dir>Cross build into <dir>/build/phone-release/
tools/zrn push <host> <dir>Upload to ~/zrn-dev/<name>/, with the fonts and theme in ~/zrn-dev/share/
tools/zrn run <host> <dir> [args]Build, push and run. Arguments after the directory go to the app
tools/zrn watch <host> <dir>Run again when a source changes. Needs inotify-tools

ZRN_HOST makes the host optional. ZRN_PRESET=phone-debug builds a debug binary.

Static linking

The phone-* presets turn off the shared libraries. The app is linked statically with zrnui and zrnapp, so one file goes up. The phone needs only its system libraries: wayland, freetype, mesa. The fonts and theme.ini are passed with ZRNUI_FONT_DIR and ZRNUI_THEME.

As a system package

zrnui, zrnapp, zrnkit and demoapp each have a PKGBUILD. makepkg -si in zrnui, then zrnapp, installs the libraries. An app can follow the demoapp PKGBUILD.

.zexec format 2 coming

A signed store package for v2 apps. Its layout, signing and submission flow are not in the pinned commit, so this site does not describe them yet.

Checked against zrn-sdk commit 71a5ace (SDK v2).
