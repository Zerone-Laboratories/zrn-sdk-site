Troubleshooting

Errors as the tools print them, and the fix.

You seeDo this
cmake --build --preset ... says the build directory does not existConfigure first: cmake --preset host-debug
Errors about nullptr, constexpr or autoThe compiler is too old for C23. Use GCC 13+ or Clang 19+
zrn: which project? e.g. examples/helloworldGive the project folder after the host
zrn: ... has no CMakePresets.jsonCopy CMakePresets.json from an example into your project
zrn: which device? ...Give the phone's address, or set ZRN_HOST
no aarch64 sysroot at ...Run tools/zrn sysroot
exec format error while the sysroot buildsRegister binfmt for aarch64 (qemu-user-static-binfmt)
Permission denied (publickey)tools/zrn -p - setup-key <host>
REMOTE HOST IDENTIFICATION HAS CHANGEDThe phone was reflashed: ssh-keygen -R <host>
Permission denied when the app starts on the phoneHome is mounted noexec: set ZRN_REMOTE_DIR elsewhere
no Wayland socket in /run/user/...Log in on the phone, or set ZRN_WAYLAND_DISPLAY
Text shows as boxesThe fonts were not found. Check ZRNUI_FONT_DIR, or ~/zrn-dev/share/fonts on the phone
Only Latin letters drawBuild with fontconfig
Zinit returns falseThe fonts could not load. Print Zget_error_message()
Zwindow_run_ex returns false at onceNo Wayland session, or an invalid root. Print Zget_error_message()
Nothing animatesThe software renderer is in use. Animations need the GPU renderer, or ZRNUI_ANIMATIONS=on
A rotation or slide is ignoredRender transforms are drawn only by the GPU renderer

Checked against zrn-sdk commit 71a5ace (SDK v2). Pictures and clips are drawn by zrnui's GLES2 renderer, offscreen, from code that compiled, against the zrn-sdk working tree on top of that commit (it adds the app bar measured on a Windows Phone 8.1 phone and the Segoe WP font lookup), in Segoe WP.
