Ways to make an app

Write C against zrnui and zrnapp. That is the only supported way in SDK v2.

WayLinksStatus
C23, an ordinary Wayland appzrnui and zrnappSupported. Runs on a laptop and on a phone
C++, including the C headerszrnui and zrnappWorks. No C++ wrapper
zrnui inside your own shellzrnui onlySupported. You drive input, time and frames
Python, Rust-No bindings in v2
Older Python SDK, ztosQtOlder. Part of the ztOS tree, not of zrn-sdk

The two libraries

LibraryWhat it is
zrnuiThe element tree, layout, every control, theme, text, and two painters: software and OpenGL ES 2. It opens no window and has no event loop.
zrnappA Wayland window on top of zrnui: the event loop, pointer, touch and keyboard, the shell's scale, and frames to the compositor.
zrnkitA metapackage that installs both.

There is no umbrella zrnui.h. Include what you use: zrnui/controls.h, zrnui/host.h, and zrnapp.h. Each header includes the one it builds on.

From C++

The headers are plain C. A C++ program includes them as they are. C23 nullptr and constexpr are inside the library, not in the headers you call.

#include <zrnapp.h>
#include <zrnui/controls.h>
#include <zrnui/host.h>

A callback is a plain function pointer. A capturing lambda does not convert to one: pass state through user_data.

Inside your own shell

Link zrnui alone. Your loop injects input, ticks time and takes frames.

ZConfig config;
Zconfig_default(&config);
config.font_directory = "/usr/share/fonts/zrnui/selawik";
if (!Zinit_ex(&config)) return 1;

const Zid root = Zroot_create();
Zroot_set_size(root, 480, 800);
Zroot_set_visual(root, page);

for (;;) {
    Zroot_inject_pointer(root, Z_POINTER_DOWN, x, y);
    Zroot_tick(root, dt_ms);
    ZFrame frame = {0};
    if (Zroot_render(root, &frame)) present(frame.pixels, frame.width, frame.height, frame.stride);
}

A frame is 8-bit RGBA, top row first, owned by the root until the next render. This is how the pictures on this site are made. zrnui/docs/embedding.md has the GPU target and input details.
