Animations

Animations run only with the GPU renderer, unless Zroot_set_animations forces them. With the software renderer every change happens at once. Time moves only through Zroot_tick.

Each clip below is a recording of zrnui itself, from the working tree on top of the pinned commit: the GLES2 renderer offscreen, time moved by Zroot_tick in steps of 1/60 s, every frame read back, input injected as a finger. The program is gen/anim.c. Clips loop with a short pause.

Page transitions

Zframe_set_transition(frame, Z_TRANSITION_TURNSTILE);   // the default
Zframe_set_transition(frame, Z_TRANSITION_NONE);

It takes effect from the next navigation. A Navigate or GoBack during a transition ends it at once. Zframe_is_transitioning says whether one runs.

Animate an element

void fade_in(Zid element) {
    Zelement_set_opacity(element, 0.0f);
    Zelement_animate(element, Z_PROP_OPACITY, 1.0f, 300.0f, Z_EASE_OUT, 0.0f);
}

Zelement_animate(element, property, to, duration_ms, easing, delay_ms) moves a property from where it is now. A new animation of the same property replaces the running one. With animations off, the property jumps.

Properties: Z_PROP_OPACITY, Z_PROP_ROTATION_X, Z_PROP_ROTATION_Y (degrees), Z_PROP_SCALE, Z_PROP_TRANSLATE_X, Z_PROP_TRANSLATE_Y.

EasingCurve
Z_EASE_LINEARLinear
Z_EASE_OUTCubic: quick start, soft end
Z_EASE_INCubic: slow start
Z_EASE_EMPHASIZEDCubic Bezier (0.2, 0.8, 0.2, 1): quick start, long soft settle

Render transforms

Zelement_set_projection (a PlaneProjection), Zelement_set_render_scale and Zelement_set_translate change how an element is drawn, not its layout. Only the GPU renderer draws them. A transformed element is still hit where layout put it.

Zelement_set_tilt(element, on) turns tilt on or off. It is on by default for list and grid items, group headers, hyperlinks, check boxes, radio buttons and menu items. It is off for Button.
