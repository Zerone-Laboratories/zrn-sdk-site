Getting started

You can write and run an app on a Linux computer with a Wayland session. A phone is only needed to check touch, scale and speed.

What you need

  • A C23 compiler: GCC 13 or newer, or Clang 19 or newer.
  • cmake 3.21 or newer (for presets), ninja, pkgconf, freetype2, libpng.
  • For the window: wayland, libxkbcommon, wayland-protocols. For the GPU renderer: mesa (EGL, GLES2).
  • fontconfig, optional. Without it only the Latin letters of the bundled Selawik fonts are drawn.
sudo pacman -S --needed base-devel cmake ninja pkgconf freetype2 libpng fontconfig mesa wayland libxkbcommon wayland-protocols

Your first app

There is no top-level CMakeLists.txt. Each part is its own CMake project. An example pulls in ../../zrnapp, and zrnapp pulls in ../zrnui.

git clone https://github.com/Zerone-Laboratories/zrn-sdk
cd zrn-sdk/examples/helloworld
cmake --preset host-debug             # configure first
cmake --build --preset host-debug
./build/host-debug/helloworld

This is examples/helloworld/hello.c:

#include <stdint.h>
#include <stdio.h>
#include <zrnapp.h>
#include <zrnui/controls.h>
#include <zrnui/host.h>

/* The first page: a title and a line of text. */
static Zid main_page(const Zid frame, void* const parameter) {
    (void)frame;
    (void)parameter;
    const Zid page = Zpage_create();
    const Zid stack = Zstack_panel_create(Z_VERTICAL);
    Zpage_set_content(page, stack);
    Zelement_set_margin(stack, Zthickness(19, 32, 19, 0));

    const Zid title = Ztext_block_create("HELLO WORLD");
    Ztext_block_set_style(title, Z_TEXT_STYLE_TITLE);
    Zpanel_add(stack, title);

    const Zid text = Ztext_block_create("zrnui in a few lines of C");
    Ztext_block_set_style(text, Z_TEXT_STYLE_PHONE_TITLE2);
    Zpanel_add(stack, text);
    return page;
}

int main() {
    if (!Zinit()) return 1;
    // the size comes from the shell (the compositor configure)
    const Zid root = Zroot_create();

    // App::OnLaunched: a Frame is the content of the window, then it navigates to the first page
    const Zid frame = Zframe_create();
    Zroot_set_visual(root, frame);
    if (!Zframe_navigate(frame, main_page, (void*)(uintptr_t)root)) {
        fprintf(stderr, "helloworld: %s\n", Zget_error_message());
        Zroot_destroy(root);
        Zshutdown();
        return 1;
    }

    // the window runs until it is closed, or Back is pressed on the first page
    // the title is for people; the app id (what the shell matches with helloworld.desktop) is the name of the executable
    const ZWindowOptions window = { .title = "Hello World" };
    const int ok = Zwindow_run_ex(root, &window);
    if (!ok) fprintf(stderr, "helloworld: %s\n", Zget_error_message());
    Zroot_destroy(root);
    Zshutdown();
    return ok ? 0 : 1;
}

examples/demoapp is a tour of the controls, with pages for buttons, text, a Pivot and a Hub.

Handles

Every object is a Zid, a 32-bit handle. A handle holds an index and a generation, so a handle of a destroyed object is caught and reported, not a crash. Z_INVALID_ID (0) is never valid. A create function returns it on failure. The reason is in Zget_error() and Zget_error_message().

A parent owns its children. Zelement_destroy destroys an element and everything under it. Nothing in the library is thread-safe: use it from one thread.

The life cycle

if (!Zinit()) return 1;           // fonts, theme, $ZRNUI_* settings
Zid root = Zroot_create();        // a root hosts one visual tree
Zroot_set_visual(root, frame);    // the root owns it
Zwindow_run_ex(root, &options);   // zrnapp: window and event loop
Zroot_destroy(root);
Zshutdown();

Zinit returns false when the fonts cannot be loaded. Zinit and Zshutdown are counted. A root has a size, a theme, an accent and a renderer.

Building a tree

Create with Z<class>_create, set properties with Z<class>_set_<property>, and add to a parent.

ParentHow to add a child
A panel: StackPanel, Grid, CanvasZpanel_add(panel, child)
A content control: Button, Page, ScrollViewerZ..._set_content(control, child)
An items control: ListView, ComboBoxZitems_control_add, Zitems_control_add_text

Sizes are logical pixels on a 480 x 800 grid. The shell's scale enlarges the picture, not the grid.

Pages and Back

An app is normally a Frame that shows Pages. A page is made by a factory function, so the frame can build it again on the way back: Zframe_navigate(frame, factory, parameter), then Zframe_go_back(frame). The shell already places the window below its status bar, so a Frame starts at the top (set ZRNUI_SAFE_AREA_TOP to reserve room yourself).

Back (Escape on a keyboard) closes the top popup, flyout or dialog, else an open app bar, else goes back in the Frame. On the first page zrnapp closes the window.

Events

Use the typed helper when there is one, such as Zbutton_on_click, or Zelement_on(element, Z_EVENT_..., callback, user_data). A callback is void callback(Zid sender, void* user_data). Read the new state from the sender. A handler may destroy its own control or navigate away.

static void on_click(const Zid sender, void* const user_data) {
    Zroot_back((Zid)(uintptr_t)user_data);
}
Zbutton_on_click(button, on_click, (void*)(uintptr_t)root);

Time

Animations, the caret, repeat buttons, scrolling inertia and tooltips move only through Zroot_tick(root, dt_ms). zrnapp calls it about every 16 ms.
